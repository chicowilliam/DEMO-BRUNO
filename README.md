# Demo Cafe com Letras

Demo institucional e de experiencia para apresentacao ao proprietario do Cafe com Letras.

## Stack

- React
- Vite
- Tailwind CSS
- Sem backend (versao demo)

## Conceito

Esta versao foi estruturada com inspiracao em referencias premium de lifestyle e editorial, com foco em:

- Hero forte com narrativa de marca
- Navegacao clara por secoes
- Blocos de cardapio, programacao e eventos
- Secoes institucionais (noticias, sobre, contato)
- Visual responsivo para desktop e mobile

## Como rodar

1. Instale dependencias:

   npm install

2. Rode em desenvolvimento:

   npm run dev

3. Gere build de producao:

   npm run build

4. Visualize build local:

   npm run preview
